# ADR-006: 有効な夫婦スペース所属を1ユーザー1つに制限する

- Status: Accepted
- Date: 2026-08-24

## Context

MVPは対等な2者専用であり、複数の有効スペースや3人目の参加を許すと権限とUXの前提が崩れる。

## Decision

1ユーザーにつき有効な夫婦スペースは1つ、1夫婦スペースにつき有効ユーザーは最大2人とする。招待参加は認証済みユーザーに限り、transaction内で双方の上限を再検証する。可能な範囲をDB制約で保証し、競合する同時参加も拒否する。

## Consequences

UIの選択状態に依存せず所属が一意になる。脱退・再ペアリングを実装するときも過去membershipは削除せず無効化日時を残す。
